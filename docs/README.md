# fal Serverless docs, in Markdown

Copies of fal Serverless documentation pages that the examples in this repo rely on, kept here in plain Markdown so they can be read next to the code. Each page links to its source; the docs site is the source of truth.

- [Serverless pricing](serverless-pricing.md): how runners are billed per second by state, the GPU-count multiplier, and the per-hour and per-second GPU prices
- [Deploy a ComfyUI workflow as an API](comfyui-workflow-api.md): export the workflow's API JSON, package custom nodes and models, deploy, autoscale, and call it
- [Migrating a Cog model or custom container](migrate-cog-or-custom-container.md): run an existing Cog image, build from a Dockerfile, or convert a `Predictor` to a `fal.App`
